# 长江下游流域降水事件产流分析软件 V1.1

本软件使用 TR-55 曲线数法估算降水事件产流，支持多流域计算、前期湿润条件设置、参数敏感性分析及结果导出。仓库包含本地版与云端版源码。研究数据、数据库、栅格、空间权重、年度覆盖统计和部署配置单独管理。

[查看 V1.1 更新公告](CHANGELOG.md) · [使用云端软件](https://yangtze-event-runoff-xg.upperjelly5.chatgpt.site)

## 软件使用说明

### 无数据试用

在仓库根目录运行以下命令，用浏览器打开 [本地示例页面](http://127.0.0.1:8765/)。

```bash
python -m http.server 8765 --bind 127.0.0.1
```

展开「导入单元资料与示例」，点击「计算合成示例」。静态服务下，如页面提示资料库不可用，仍可使用合成示例查看结果及导出功能。试用结束后按 Ctrl+C 关闭静态服务，避免与完整服务占用同一端口。

### 本地计算真实事件

1. 安装 Python 3 和地理数据处理依赖。

   ```bash
   python -m pip install numpy rasterio netCDF4
   ```

2. 自行准备 CLCD 土地利用和 HYSOGs250m 水文土组单波段 GeoTIFF。土地利用放入 `CLCD核心研究区裁剪成果/`，按 `序号_流域名_CLCD_年份.tif` 命名。土组放入 `data/HYSOGs250m/`，按 `序号_流域名_HYSOGs250m.tif` 命名。两类文件的流域名应一致。运行 `python database.py` 建立索引，更新栅格后可重跑。
3. 准备 CN05.1 日降水 NetCDF。在仓库根目录使用以下命令导入，把参数换成实际文件路径。

   ```bash
   python -c "from precipitation import import_rain; import_rain(r'path/to/precipitation.nc')"
   ```

4. 运行 `python server.py`，打开 [本地服务](http://127.0.0.1:8765/)。展开「本地数据库与 CN 参数」，导入 CN 参数 JSON。文件应为数组，每条记录包含 `landCode`、`soil` 和 `cn`，可附 `source`、`conditions` 记录取值依据。土组用 A、B、C 或 D，CN 值大于 0 且不超过 100。
5. 选择流域、事件起止日期和前期湿润度日期。默认建议使用事件前五天，可根据研究依据调整湿润判据、排水情景和初损系数。点击「计算所选流域产流」。
6. 在「分流域结果」中查看陆地产流、水面直接降水输入及有效覆盖率。需要比较参数时可展开「参数敏感性」。点击「下载 CSV」保存汇总，或点击「下载复算 JSON」保存复算所需输入。复算文件可从「导入单元资料与示例」重新导入。

可运行 `node --test runoff.test.cjs result-view.test.cjs` 验证产流计算核心。

### 云端构建

进入 `cloud/`，执行 `npm ci` 和 `node build.mjs`，构建产物位于 `cloud/dist/`。完整运行需要配置后端运行环境、`BUCKET` 存储绑定，以及符合服务端格式的资料目录、降水和空间权重。共享资料写入还需要配置 `ADMIN_WRITE_TOKEN`。

## 已知使用缺陷与适用限制

| 限制 | 对使用的影响 |
| --- | --- |
| 完整本地服务依赖栅格和数据库 | 仅下载源码时，直接执行 `python server.py` 会因缺少土地利用或土组栅格而无法启动。可先按上面的静态服务步骤试用。 |
| 本地降水导入器针对固定数据规格 | 当前要求 `pre(time, lat, lon)`、日尺度、递增的 0.25° 经纬网格，并检查 1980–2022 年日期连续性。其他范围或网格的 NetCDF 需要先调整导入逻辑。 |
| 土地利用按事件开始年份匹配 | 缺少该年份图层时无法进行对应的真实事件计算。跨年事件全程使用开始年份的地表资料。 |
| 缺测会影响可计算面积 | 降水、土组或 CN 缺失可能导致单元被排除。覆盖率以 CLCD 有效分类面积为分母，使用结果时应同时检查有效覆盖率和排除原因。 |
| 空间叠加存在分辨率限制 | 计算按栅格像元中心分配降水格点及土组，边界附近和小尺度地块的结果受源数据分辨率影响。展示矩形所覆盖的区域应按其实际范围解读。 |
| TR-55 结果依赖参数与假设 | CN 映射、前期湿润度、排水情景和初损系数都会影响估算。软件输出事件产流量及水面直接降水输入，流域出口流量过程还需要汇流计算。 |
| 云端版依赖自行配置的数据 | 构建后仍需配置存储和配套数据，才能使用完整的在线资料查询与计算功能。 |
